## 1. 背景与目标

### 1.1 背景

当前入库流程默认「一张照片 = 一个字」。博主实际拍摄时，常见一张图里有多个字（条幅、册页、练习纸、碑帖局部）。若逐字裁切再上传，成本高、易丢上下文。

希望增加一条入库路径：上传整图 → 划出每个字的区域 → 去底成透明 PNG → 批量写入现有 `character_assets`，供集字工作台继续使用。

### 1.2 一句话目标

**把「多字原图」可靠地拆成可检索、可集字的透明背景单字素材。**

### 1.3 成功标准

| 标准 | 口径 |
| --- | --- |
| 主路径可走完 | 上传 → 区域确认 → 抠图预览 → 填写汉字 → 一键入库 |
| 自动失败可兜底 | 自动识别不准或失败时，可完全手动框选 / 改框 / 删框 |
| 与现有库兼容 | 产出记录格式与现有单字素材一致，能在 `/assets` 检索、能在集字中选用 |
| 本机可用 | 不依赖公有云账号；网络不可用时至少可走「手动标注 + 本机抠图」 |

### 1.4 非目标（本需求不做）

- 不生成矢量字 / TTF  
- 不做多人协作标注  
- 不保证碑帖、严重残缺、字与字严重粘连场景的自动识别准确率  
- 不替代单张单字上传（原 `/assets` 上传入口保留）  
- 不把整图本身当作可集字素材；整图仅作加工源

## 2. 角色与场景

| 角色 | 说明 |
| --- | --- |
| 唯一用户 | 书法博主本人（与大纲一致，单人本机） |

| 场景 ID | 场景 | 期望结果 |
| --- | --- | --- |
| S1 | 拍了一张练习纸，约 8–20 个字，背景接近宣纸白 | 自动框出大部分字；少量漏检用手动补；去底后入库 |
| S2 | 自动识别框不准或漏字 | 可拖拽改框、增删框；不依赖自动结果也能入库 |
| S3 | 自动识别完全不可用（模型未装 / 失败） | 进入纯手动标注模式，其余流程不变 |
| S4 | 同一张图拆出多个同字 | 各自成为独立素材（同字多写法），互不覆盖 |
| S5 | 中途不想提交 | 可放弃会话；不写入素材库；临时文件可清理 |

## 3. 用户流程

```text
[素材库] 点击「多字入库」
        │
        ▼
   上传一张原图（或从本地选择）
        │
        ▼
   进入切分工作台（会话）
        │
        ├─【可选】自动检测文字区域 → 生成候选框
        ├─ 用户增 / 删 / 改框，并为每框填写汉字（必填）
        ├─【可选】批量或逐字预览抠图（透明底）
        │
        ▼
   确认入库
        │
        ▼
   每个有效框 → 裁切 → 抠图 → 写 originals/thumbs → 插入 character_assets
        │
        ▼
   跳转素材列表（可筛选刚入库批次）或留在工作台提示成功数
```

交互原则：

1. **自动是加速，不是门槛**：无框也能完成。  
2. **汉字由用户确认**：自动 OCR 若有，仅作建议值，入库前必须可改。  
3. **抠图结果可预览**：不满意可跳过该字、重试或保留不透明裁切（见第 5.3 节降级策略）。

## 4. 功能需求

### 4.1 入口与页面

| 项 | 要求 |
| --- | --- |
| 入口位置 | `/assets` 页增加「多字入库」按钮；与现有「上传单字」并列 |
| 路由 | **已锁定** `/assets/split` |
| 返回 | 可随时返回 `/assets`；未确认入库不产生素材记录 |

### 4.2 上传

| ID | 需求 | 优先级 |
| --- | --- | --- |
| F-UP-01 | 支持常见格式：JPEG / PNG / WebP | P0 |
| F-UP-02 | 单次会话一张图（MVP）；多图排队留到后续 | P0 |
| F-UP-03 | 限制单文件大小（建议默认 20MB，可配置）；超限明确报错 | P0 |
| F-UP-04 | 上传后展示原图预览，并记录宽高 | P0 |
| F-UP-05 | 原图先落入会话临时目录，确认入库后再进入正式 `uploads/originals/` 派生文件 | P0 |

### 4.3 文字区域：自动识别（可选能力）

| ID | 需求 | 优先级 |
| --- | --- | --- |
| F-DET-01 | 提供「自动识别区域」操作；成功则在图上叠加候选矩形框 | P1 |
| F-DET-02 | 识别失败或超时须提示原因，并自动落入手动模式，不阻断流程 | P0（失败处理） |
| F-DET-03 | 每个候选框可带建议汉字（若接 OCR）；置信度低于阈值时建议值留空 | P2 |
| F-DET-04 | 自动结果可一键「清空全部框」后重来 | P1 |

实现备注：

- 检测可评估浏览器端轻量模型、本机 CLI、或连通域（书法白底黑字）。  
- **Step 05 / M1 不含自动检测**；M2 再开 step。

### 4.4 文字区域：手动标注（必做）

| ID | 需求 | 优先级 |
| --- | --- | --- |
| F-ANN-01 | 支持拖拽绘制矩形框（轴对齐矩形即可，MVP 不做旋转框） | P0 |
| F-ANN-02 | 选中框后可拖动、缩放四角 / 边缘 | P0 |
| F-ANN-03 | 可删除单个框；支持键盘 Delete / Backspace | P0 |
| F-ANN-04 | 每个框必须绑定恰好 1 个汉字（校验规则与现有 `createAssetSchema` 一致） | P0 |
| F-ANN-05 | 框列表侧栏：序号、汉字、尺寸；点击列表可定位画布上的框 | P0 |
| F-ANN-06 | 框之间允许轻微重叠；入库时各框独立裁切，互不影响 | P0 |
| F-ANN-07 | 最小框尺寸限制（如短边 ≥ 24px），过小禁止确认 | P0 |
| F-ANN-08 | 可选：按阅读顺序自动排序框序号 | P2 |

坐标约定：

- 框使用相对原图像素的整数矩形：`{ x, y, width, height }`，原点在图像左上。  
- 前端展示时随缩放变换，**持久化与裁切一律用原图像素**。

### 4.5 抠图（透明背景）

| ID | 需求 | 优先级 |
| --- | --- | --- |
| F-MAT-01 | 对每个确认框：先按矩形裁切，再生成透明背景 PNG（墨迹保留，纸色变透明） | P0 |
| F-MAT-02 | 支持预览：棋盘格背景查看透明度 | P0 |
| F-MAT-03 | 支持逐字预览抠图结果后再入库 | P0 |
| F-MAT-04 | 提供简单参数（可选）：阈值 / 去底强度；MVP 可先固定默认参数 | P1 |
| F-MAT-05 | 抠图失败时：允许该字以「不透明裁切图」入库并打标签 `未去底`，或跳过该字 | P0 |
| F-MAT-06 | 输出 PNG 须带 Alpha；缩略图由去底结果生成（与现有 thumbs 策略一致） | P0 |

技术路径：

| 路径 | 说明 | 适用 |
| --- | --- | --- |
| A. 前端 `@imgly/background-removal` | 通用去底，体积大 | 复杂底纹 |
| B. 服务端纸色阈值 + sharp | 白底/均匀纸色，轻量 | **已锁定为 M1 默认** |
| C. rembg 等本机模型 | 效果好，部署重 | 后续增强 |

### 4.6 确认入库

| ID | 需求 | 优先级 |
| --- | --- | --- |
| F-IN-01 | 「确认入库」仅提交：汉字已填、尺寸合法、未标记跳过的框 | P0 |
| F-IN-02 | 每框写入一条 `character_assets`，字段与现有单字上传对齐 | P0 |
| F-IN-03 | 可批量设置默认书体 / 来源 / 标签，再允许单框覆盖 | P0 |
| F-IN-04 | 部分失败时返回成功列表 + 失败原因，**已成功的保留** | P0（已锁定） |
| F-IN-05 | 成功后清理该会话临时文件 | P0 |
| F-IN-06 | `source` 默认「多字切分」或带原图文件名 | P1 |
| F-IN-07 | 同批共享 `batchId` 列 | P1（**M1 用 tags `切分入库`；M2 再加列**） |

### 4.7 与现有功能关系

| 现有能力 | 关系 |
| --- | --- |
| 单字上传 | 保留；多字入库是并行入口 |
| `/assets` 检索 / 编辑 / 软删除 | 切分产出物完全复用 |
| 集字工作台 | 无改动；透明 PNG 参与合成须验收无黑底 |
| sharp 缩略图 | 对去底结果再生成 thumbs（可 flatten 白底，与现网一致） |

## 5. 数据与存储

### 5.1 会话（切分工作台临时态）

MVP：会话不落 SQLite；服务端临时目录 + 前端状态。刷新可丢，可接受。

```text
uploads/
  _sessions/{sessionId}/
    source.{ext}        # 上传原图
    meta.json           # 尺寸、文件名等
    preview/            # 可选：预览缓存
```

框草稿可仅存前端；`commit` 时一次性提交完整 `regions`。

### 5.2 正式素材

现有 `character_assets` **主表结构 M1 不动**。

| 约定 | 说明 | 优先级 |
| --- | --- | --- |
| `tags` | 自动附加 `切分入库`；去底失败附加 `未去底` | P0 |
| `batch_id` 列 | M2 再加 | P1 延后 |
| 追溯 | `source` / `note` 写「多字切分」即可 | P1 |

```text
uploads/
  originals/{assetId}.png   # 去底后的单字 PNG（优先）
  thumbs/{assetId}.jpg      # 与现网一致
  _sessions/…               # 临时
```

### 5.3 降级策略

| 情况 | 行为 |
| --- | --- |
| 自动检测不可用（M1 无此按钮） | — |
| 单字抠图失败 | 跳过 / 不透明入库并标 `未去底` |
| 会话丢失 | 提示重新上传 |
| 大图内存压力 | 画布显示降采样；裁切/抠图一律服务端 |

## 6. API 契约

| 方法 | 路径 | 说明 | M1 |
| --- | --- | --- | --- |
| `POST` | `/api/split/sessions` | multipart 上传原图，创建会话 | ✅ |
| `GET` | `/api/split/sessions/:id` | 会话元数据 + 原图媒体 URL | ✅ |
| `POST` | `/api/split/sessions/:id/detect` | 自动区域检测 | ❌ M2 |
| `POST` | `/api/split/sessions/:id/preview` | 单 region 去底预览 | ✅ |
| `POST` | `/api/split/sessions/:id/commit` | 批量写入 assets | ✅ |
| `DELETE` | `/api/split/sessions/:id` | 放弃会话 | ✅ |

`commit` 请求体：

```ts
{
  defaults: { style, source?, tags?, note? }
  regions: Array<{
    id: string
    x: number; y: number; width: number; height: number
    char: string
    skip?: boolean
    matte?: boolean // 默认 true；false = 不透明裁切入库
  }>
}
```

`commit` 响应：

```ts
{
  batchId: string // M1 可生成 UUID 仅回传，不入库列
  succeeded: Array<{ regionId: string; assetId: string; char: string }>
  failed: Array<{ regionId: string; char?: string; reason: string }>
}
```

媒体：扩展现有 `/media/**`，允许只读 `_sessions/{id}/…`（仍禁止路径逃逸与可写暴露）。

## 7. 界面结构

```text
/assets/split
├─ 顶栏：返回 | 会话状态 | 放弃 | 确认入库
├─ 主区：原图画布（缩放、平移、绘制/调整框）
│    └─ 工具：添加框 | 删除 | 预览去底
└─ 右侧栏：
     ├─ 默认元数据（书体、来源、标签）
     ├─ 区域列表（汉字、跳过）
     └─ 选中项预览（棋盘格）
```

UI：Naive UI；标注画布：**vue-konva**（Step 05 锁定）。

## 9. 验收标准

### 9.1 功能验收（M1）

- [ ] 从 `/assets` 进入多字入库，上传一张多字图  
- [ ] 仅手动框选 ≥ 3 个字并填写汉字，可成功入库  
- [ ] 入库后 `/assets` 可见缩略图；按字检索可得；tags 含 `切分入库`  
- [ ] 去底结果在棋盘格下可见透明；墨迹目测可接受  
- [ ] 可跳过或「未去底」入库，有明确提示  
- [ ] 放弃会话不产生素材记录，临时目录被清理  
- [ ] 集字选用透明字后导出 PNG 无异常黑块  

### 9.2 质量验收

- [ ] 汉字校验与现网一致  
- [ ] 非法框（过小 / 越界）无法 commit  
- [ ] API 错误信息中文可读
